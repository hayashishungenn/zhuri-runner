# 美术风格规范（Phase 5）

> 目标：统一国风神话风格的可执行视觉语言，兼顾微信小游戏包体/内存/中低端手机性能。
> 本文档是渲染层所有视觉决策的约束源；改动须同步本文件与测试基线。

## 1. 总体方案：风格化剪影 + 渐变天穹（Stylized Silhouette）

不追求写实 PBR。采用**扁平纯色 + 剪影轮廓 + 大气透视**的风格化方案：

- 所有 3D 物体使用 `builtin-unlit` 纯色材质（免光照计算、免贴图内存，中低端机友好）
- 层次感由**色彩明度分级**表达：远山最暗 → 地面暗 → 跑道中 → 角色/障碍最亮
- 深度感由**大气透视**表达：WorldShift + 色带天空 + 雾色一致的地平线
- 光照叙事由**天空分段渐变**（12 色带，随逐日进度从深夜向暖阳过渡）承担，DirectionalLight 仅为 P2 标准材质预留

该方案的取舍：无贴图/无实时光影 → 主包极小（脚本+配置 <1MB、音频 1.4MB）、中低端机可稳定 30fps+。

## 3. 角色比例（夸父 v2）

- 头身比 ≈ 1:3.5（上古巨人：宽躯干 0.4 世界单位、粗壮四肢 0.19 半径）
- 身高 ≈ 1.8 世界单位；跑步轮辐：runPhase 与速度联动（脚步动画与音效同步，杜绝滑步）
- 神话元素：腰带/兽皮战裙/发髻/桃木神杖（杖头灵光珠琥珀色发光点）
- 8 套皮肤 = 身体/神杖 tint 重着色 + 专属几何配件（肩甲/披风/斗笠/腕环/羽冠/光环等），存档循环切换

## 4. 动画

- 状态机（CharacterAnimator 接口）：idle/run/jump/slide/stumble/dead —— 判定一致性由核心驱动（jumpT 窗口即跳跃动画窗口）
- 姿势全部为**程序化参数驱动**（跑动相位/跳跃进度/俯冲时长），天然连续过渡，无关键帧跳变
- 脚步滑动检查：runPhase += dt×(6+speed×0.35)，步频随速度线性增加；脚步音效按 runPhase 每 π 触发与视觉同步

## 5. 地形与地块模板

- 42 种数据驱动模板（tile-templates.json）：4 主题 × 10 基型 + 2 过渡
- 装饰类型 10 种基元（pillar/arch/post/banner/tree/rock/lantern/reed/crystal/urn），按主题 tint 着色
- 复用：装饰节点池化、ribbon 网格按段构建销毁、材质共享缓存（同色同实例）

## 6. 特效

- 几何粒子：奔跑扬尘/撞击碎裂/落地尘土（池化球体，寿命/重力/透明度模拟）
- 屏幕层：红闪（撞击）、热浪（高温脉冲）、慢动作黑边（死亡）、速度线（疾行）

## 7. 音频

- 全部为程序化合成原创 WAV（tools/gen-audio.js，五声音阶宫调 A）
- BGM 19.2s 古筝风循环（423KB）+ 环境风 6s 无缝循环（258KB）+ 19 个音效
- 总预算 ≤2MB（实测 1.4MB），AudioMgr 池化播放、静音联动

## 8. 性能预算（中低端机）

| 项 | 预算 |
|----|------|
| draw call | ≤250（unlit 无贴图，批处理友好） |
| 主包 | <4MB（当前脚本+音频 ≈2.5MB） |
| 材质实例 | 共享缓存按色键复用 |
| 粒子 | 池化上限 24 活跃 |
