# 已知缺陷 / 技术债

| # | 描述 | 影响 | 计划 |
|---|------|------|------|
| 1 | 复活广告为模拟实现（倒计时），真机需 `ad.mode=wx` + 真实 adUnitId | 无真实变现 | P4 |
| 2 | 3D 渲染未经过编辑器视觉验收（相机/尺度为首版参数） | 视觉手感可能需调优 | 用户预览后调参（全部在配置/常量中） |
| 3 | 3D 层每个 MeshRenderer 独立 draw call（约 150~250 个） | 低端机帧率风险 | P3 合批/DR |
| 4 | 实体用数组 + splice 管理，未做对象池（核心层）；渲染层节点已池化 | 核心 GC 抖动 | P3 |
| 5 | 无音效/音乐（静音按钮仅为状态开关） | 体验不完整 | P2 |
| 6 | 几何体占位美术（非最终视觉；规范要求正式版不得残留占位） | 视觉简陋 | P2 替换真实资产 |
| 7 | 无本地存档（最佳纪录等） | 留存体验缺失 | P2 |
| 8 | 3D 渲染器无 P0 的环绕速度线（屏幕空间特效）；高速感靠 3D 透视本身 | 高速反馈略弱 | P2 评估补充 |
| 9 | 3D 层无敌闪烁用整节点显隐替代 P0 半透明闪烁（透明材质未引入 3D 层，规避微信端混合排序问题） | 视觉细节差异，可接受 | P3 评估透明材质 |
| 10 | wx 分享/云开发等平台能力未接入 | 平台功能缺失 | P3 |
| 11 | 跨帧率事件计数不一致（拾取数随帧长差 ~9%）：生成阈值按帧累加，阈值跨越帧不同导致 RNG 交错翻转 | 仅影响回放级一致性，运动一致（0.01%）；玩家无感 | 若需严格回放：生成阈值改距离驱动采样 |
| 12 | 同种子每次重开路径相同（可复现优先，map.seed 固定） | 玩家可背板；影响新鲜感 | P3 换随机源/每日种子 |
| 13 | 桥墩/洞拱/护栏/门架为几何体占位 | 视觉简陋（规范允许占位须标记） | 美术阶段替换 |
| 14 | 弯道前后为无障碍缓冲带（转弯+避障复合未开启） | 转弯段玩法密度下降 | P3 调参开启 |
| 15 | 极端难度下完美玩家模拟器残余死亡 ≤1/30种子×60s（启发式驱动器规划局限） | 非可达性缺陷——逐波重放验证全部可达；真人可提前预判 | 持续观察 |
| 19 | 云存档（微信云开发）未接入 | 换机存档不跟随 | P5 平台联调可选项 |
| 16 | 2D 回退渲染对 22 种障碍仅按 vis 基元+配色区分（不逐形状建模） | 2D 回退视觉简化 | 视需要细化 |
| 17 | library 冷启动后首次 CLI 构建竞态（导入未完成即校验场景） | 构建假失败 | 已在 build 脚本加 warmup 固化 |
| 18 | UI 页面为文本行形态（无图标/无滚动） | 长列表展示受限（成就 60 项仅展示前 7 条可领取） | 美术阶段图形化 |
