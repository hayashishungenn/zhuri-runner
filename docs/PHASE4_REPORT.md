# Phase 4 报告 —— 夸父逐日特色玩法

> 日期：2026-11-26。目标：围绕太阳、饮水、神杖及上古神州环境的原创机制；双模式完整可玩。

## 逐项交付

### 1. 逐日系统

- `core.sunProgress`：无尽 = 里程/天空全程（3 万里）；征途 = 里程/最终目标（6000 里）——**可见且可计算**
- 太阳视觉与进度绑定：位置西沉（y 10→4.5）、尺寸增大（×1~×1.7）、靠近（z −160→−154）——"追上太阳"的直观反馈
- 无尽模式：距离与最高逐日进度入存档（`zhuri.bestLi`），标题页显示最佳纪录
- 征途模式：3 阶段目标（2000/4000/6000 里，可配置递增），跨越发 stage 弹字，全部达成 → `ended` 胜利态 +「逐日功成 · 弃其杖，化为邓林」结算

### 2. 高温与饮水

- 升温：`baseRate 1.2/s × 主题 heatMul × (1 + 0.5×D)`，封顶 100
- **永不致死**：热满仅强制减速 ×0.75（公平性硬约束，测试断言 state==='run'）
- 降温三途径：甘霖降临 −40、安全跃过溪流 −10（溪流从威胁变资源）、自然衰减无
- **保底**：热量 ≥70 且 300 单位无饮水资源 → 强制生成甘霖（pity 硬约束杜绝随机缺水必然失败）
- 预警：热量条（HUD 面板内）+ ≥80 红色全屏脉冲闪烁

### 3. 神通系统（7 项 ≥ 6）

| 神通 | 效果 | 规则 |
|------|------|------|
| 桃木神杖（新） | 撞上切道/时机类障碍消耗 1 层击碎 | +3 层/次，上限 6；跳跃滑铲类不适用（本可动作通过） |
| 御风疾行 | 3s 速度 ×1.5 + 无敌 | 替换剩余 |
| 巨人之跃（新） | 10s 跳跃时长 ×1.35（更高更远） | 同类延长；落地判定/验证器覆盖窗按实际时长 |
| 灵光引聚 | 12s 吸附碎片 | 同类延长 |
| 山岳护体 | 挡一次任何撞击（含墙） | 1 层不叠加 |
| 甘霖降临 | −40 热量 + 解除踉跄减速 | 即时；拾取即重置保底窗口 |
| 阳炎倍率 | 10s 碎片 ×2 | 同类延长 |

叠加/优先级：同类取最优，异类独立计时（测试：四神通并发互不干扰）。视觉反馈：HUD 活跃列表+剩余秒、拾取弹字、3D 道具球配色旋转。

### 4. 游戏模式

- **双模式共享核心**：`core.mode` 仅影响征途判定与太阳进度计算，玩法逻辑零重复
- 标题双按钮（无尽逐日/逐日征途）+ Enter 默认无尽；征途 ended → 再来一次/无尽切换
- 无尽：死亡结算（最佳纪录刷新入档）；征途：通关 ended 结算 + `zhuri.journeyDone` 标记

### 5. 地图主题（4 种）

| 主题 | heatMul | itemMul | track 配色 |
|------|---------|---------|-----------|
| 大荒山林 | 1.0 | 1.0 | 深赭 |
| 黄河渭水 | 0.7（水乡凉） | 1.2（资源丰） | 青灰 |
| 极西荒漠 | 1.6（炙热） | 0.8（贫瘠） | 沙金 |
| 扶桑天境 | 1.2 | 1.4 | 金乌 |

主题由地图生成器按距离切换（每 400 逻辑单位，50% 过渡地块），核心按路径所在地块采样 `themeNow`：升温倍率与道具概率实时联动；渲染层色带/跑道/路缘配色随主题渐变。

## 遗留与说明

1. 构建资产库冷启动竞态：library 删除后首次 CLI 构建会因导入未完成而"初始场景不存在"假失败——已用"打开项目预热导入"固化到 build 脚本（warmup），实测恢复。
2. 主题与地图生成的联动为"距离驱动的主题索引"，四种主题的出现顺序固定循环（大荒→渭水→荒漠→扶桑）；征途模式的阶段与主题强绑定留待后续（需要生成器支持"指定区间主题"）。
3. 神通为拾取触发（无主动施放键），符合无尽跑酷操作简洁性；主动施放型神通留待 P5 评估。
