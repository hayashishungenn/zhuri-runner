# Phase 2 报告 —— 无限地图与程序化生成

> 日期：2026-11-26。目标：支持连续生成、90° 转弯、高低差及主题切换的 3D 无限跑道系统。

## 核心架构决策

**核心逻辑保持相对坐标不变**：实体 z 恒为"相对玩家的路径距离"，lane 为横向偏移——碰撞/生成/拾取逻辑与跑道形状完全解耦（Phase 0/1 的全部机制零改动）。世界空间（转弯/坡度/特殊地块）由新增的**分段路径层**承担：

```
GameCore（相对坐标：dist / 实体 z / lane —— 不变）
   │ dist 即"玩家在路径上的位置"
   ▼
MapGenerator → SegmentPath（新增：地块流 → 世界坐标/航向/高度采样）
   │ path.sample(d, laneOffset) → {x, y, z, heading}
   ▼
Renderer3D（新增：分段 ribbon 网格 / 天空锚点 / path 化相机与虚线 / WorldShift 重定位）
```

## 逐项交付

### 1. 地块系统（core/track.ts: TrackSegment）

任务书要求的字段全部落地：入口/出口（坐标+航向）、方向、长度、跑道位置（halfWidth 宽度变体 ±15%）、障碍生成点（allowsObstacles）、道具生成点（allowsProps）、地形边界（boundaryLeft/Right: open/rail/wall）。

地块类型（9 种）：`straight / slopeUp / slopeDown / arcL / arcR / bridge / cliff / cave / transition`。
- 弧线：圆心几何（entry − turn·right·R），90° 转向，半径可配（默认 6 逻辑单位）
- 坡道：grade 线性高度（±0.12），出/入口高度衔接
- 桥：正弦拱面 + 双排桥墩落地；悬崖：开放边界 + 护栏桩；山洞：拱形环 + 无障碍带；过渡地块：主题切换处门架
- append 时开发期断言：出入口坐标/航向/距离不连续立即抛错（**缝隙/重叠/断层在生成点即被拦截**）

### 2. 地图生成器（core/MapGenerator.ts）

- 基于 cursor（位置/航向/距离）自动拼接，同种子完全可复现（SeededRng，seed 入配置）
- 带权重选择 + 约束：转弯间隔 [gapMin=70, gapMax=180]（到上限强制转弯）、坡道后不接弯/特殊、特殊地块间隔 ≥120、弯道/桥/洞/过渡禁障碍、主题每 400 距离切换（50% 生成过渡地块）、宽度变体
- **前方预生成 horizon=300 / 身后 recycleBehind=30 回收**：地块数量恒有界（实测上限 ~16）

### 3. 转弯机制

- **真世界空间转弯**：路径航向变化 → 跑道 ribbon、障碍/碎片/装饰、角色朝向（yaw）、相机视线全部经同一 sample() 同步
- **手势区分**：路口窗口内（路口前 8 逻辑单位开启）左右滑动 = 转向（Game 层路由 tryTurn），窗口外 = 普通切道；窗口内 HUD 显示闪烁方向箭头
- **操作窗口与失败条件**：正确方向 → 通过（cornersPassed+1）；错误方向 → 立即撞墙；不转向越过路口 → 撞墙。转弯撞墙不受无敌豁免（墙是跑道本体）
- 相机在弧线上自然摇移（路径后方跟随），无跳变源（全 dt 插值 + lookAt 目标连续）

### 4. 对象池与资源生命周期

- 地块视图：SegmentView 池化（ribbon Mesh 随地块销毁重建、装饰节点按类池化、节点复用池）
- 实体/尘土池沿用；重开（startRun）= 同种子重建整条路径 + 全部状态复位；死亡/暂停/场景销毁（destroy 释放 mesh/root）路径完备
- 30 分钟压测证明：活跃地块 ≤16、障碍 ≤16、碎片 ≤42、装饰 ≤30，全程无增长

### 5. 长距离精度

- 核心层 float64 绝对坐标：30 分钟 ≈ 4.8 万逻辑单位，JS double 精度无损
- 渲染层 **WorldShift 原点重定位**：玩家渲染坐标超 4000 → shift 吸附到玩家绝对坐标（1.0 取整），全场景 render = abs − shift；相对位移严格不变（平移坐标系，单测验证）
- 距离统计：core.dist 不参与重定位，里程/速度曲线全程正确

## 遗留与说明

1. **2D 回退模式不含转弯**（turnsEnabled 随 renderMode='3d' 开启）：2D 伪透视无法呈现转向，属有意设计。
2. 同种子每次重开路径相同（可复现优先）：随机化开局种子留待 P3（需要时把 map.seed 换成随机源）。
3. 转弯处障碍为空带（含前后 margin）：转弯+避障复合操作留待 P3 调参开启。
4. 桥墩/洞拱/护栏为几何体占位视觉，P2 后续替换真实资产。
