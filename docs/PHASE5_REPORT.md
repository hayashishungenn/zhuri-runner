# Phase 5 报告 —— 3D 美术、动画与音频生产

> 日期：2026-11-26。目标：统一国风神话风格的完整 3D 表现 + 可持续维护的资源生产体系。

## 工具现实与生产路径（任务书要求如实记录）

**阻塞项**：本机无 Blender/Maya 等建模工具、无 ffmpeg/sox 音频工具、无图像生成插件接入。传统"建模-UV-蒙皮-烘焙"管线**不可执行**，如实记录为阻塞项。

**采用方案**（非占位、真实运行资产）：**程序化资源生产管线**——几何、材质、动画、装饰、音频全部由代码参数化生成并真实进入引擎渲染/播放。这是微信小游戏业界成熟做法（包体/内存/中低端性能三优），且 100% 原创、零第三方授权。程序化资产是**真实运行资产**（引擎每帧实际渲染/播放），不是概念图或未验证脚本。

## 逐项交付

### 1. 美术规范（docs/ART_STYLE.md）

风格化剪影 + 渐变天穹方案：全 unlit 纯色材质（免光照/免贴图）、色彩明度分级层次、大气透视深度、天空 12 色带逐日渐变。色彩规范表/角色比例（1:3.5 巨人）/性能预算（draw call ≤250、主包 <4MB、粒子池 24）全部成文并受测试约束。

### 2. 原创夸父角色 v2

- **健壮上古巨人**：躯干加宽（0.4×0.62×0.3）、四肢加粗（0.19）、胸腔体块、神话服饰（腰带/兽皮战裙）、发髻、**桃木神杖 + 杖头灵光珠**
- **8 套皮肤**（skins.json + schema 校验 ≥8）：逐日本尊/玄甲夸父/赤焰战衣/苍藤行者/金乌羽衣/渭水渔隐/荒漠旅人/扶桑神裔——每套 = 身体+神杖 tint 重着色 + **专属几何配件**（肩甲/披风/斗笠/腕环/羽冠/光环），签名唯一性测试保证非仅改名称
- 换肤：applySkin 销毁重建（标题页低频操作）、`zhuri.skin` 存档持久化、标题「换肤 ›」按钮循环切换
- 动画适配：皮肤重建保留姿势状态机（动画与几何解耦）

### 3. 人物动画（全状态）

状态机：idle/run/jump/slide/stumble/dead 程序化姿势 + **动作-判定一致性**（跳跃窗口即动画窗口；runPhase 联动步频防滑步；脚步音效按 runPhase 每 π 触发与四肢同步）。转向由 yaw 透传（转弯时角色朝向路径）。神通表现：御风（速度线+拖尾池）、神杖（击碎爆尘+弹字）、甘霖（水花+弹字）、跳（起跳尘土）、落地（尘土+音效）。过渡均为参数化连续函数（jumpT/slideT 进度驱动），无关键帧跳变；模型穿插由体型间距参数保证。

### 4. 地图资源（42 模板 ≥ 40）

- `tile-templates.json`：**42 种**数据驱动模板（≥40 达标）= 4 主题 × 10 基型（直道×4/上下坡/左右弯/桥/洞）+ 2 过渡
- 每模板含装饰布局（类型/位置/横向偏移/缩放），10 种装饰基元按主题着色
- 渲染器 `applyTemplateDecor` 按 spec 实例化；MapGenerator 注入 templateId 全链路（生成→核心→渲染）
- 复用：装饰节点池、材质共享缓存、模块化 ribbon 路面

### 5. 特效与音频

- **音频**：`tools/gen-audio.js` 纯 Node 合成 **21 个真实 WAV**（16bit/22050Hz，RIFF 头测试验证）：BGM 五声音阶古筝风 19.2s 循环、环境风无缝循环、脚步×2/金币/跳/落地/滑铲/受击/死亡/复活/御风/神杖/巨跃/甘霖/护盾/磁吸/倍率/转弯/UI/保底提示。AudioMgr：池化 SFX/BGM/环境风、静音联动、事件全接线（脚步与动画相位同步）
- **特效**：扬尘/碎裂/落地尘土（池化粒子）+ 溪流水花清凉弹字 + 神杖破障弹字 + 御风速度线（已有）+ 热浪红光脉冲（Phase 4）

### 6. 授权管理（ASSET_LICENSES.md 已更新）

全部资产（几何/材质/动画/装饰/音频/皮肤/模板）为**本项目程序化原创**，项目自有，无第三方素材混入；AI 辅助编码（工具与条款）已登记；阻塞项（无建模工具）如实记录。
