# Phase 3 报告 —— 障碍、道具与动态难度

> 日期：2026-11-26。目标：完整的躲避-收集-变难-重开循环，可控随机性、组合障碍、稳定碰撞、道具与动态难度。

## 核心架构决策

**障碍数据驱动**：22 种障碍全部定义在 `assets/resources/obstacle-catalog.json`（带 schema 校验，非法目录启动即抛错），核心判定逻辑按 `defId` 查目录执行——加障碍 = 加数据，不加代码。可达性验证器为纯函数（`core/Reachability.ts`），生成管线（`spawnWave`）每波强制调用。

## 逐项交付

### 1. 障碍系统（22 种 ≥ 20）

四类通行方式全覆盖：跳跃 11 种（岩/尖岩/巨岩/倒木/藤蔓/沟壑/断桥/溪流/火堆/火带/双岩）、滑铲 3 种（横梁/宽梁/石拱门）、切道 5 种（岩墙/尖刺墙/火墙/栅栏/石阵）、时机 3 种（往返石墩/摆木/滚石——摆动与横移逐帧更新占道）。每种携带受击等级（踉跄=可承受/死）与视觉形态（vis 基元 + 配色 + scale，3D 工厂参数化生成）。

### 2. 碰撞与判定

- 占道集合判定（1-3 道，`expandLanes` 锚点扩展 clamp）；高速穿透：判定为单点触发（z 跨 hitZ 一次）天然无区间漏判，极速 29 下 40 连跳测试证明无遗漏
- 重复受击：passed 标志 + 踉跄豁免无敌 + 护盾消耗互斥；边缘碰撞：round(laneF) 语义与 P0 一致
- 动作碰撞体变化：jump/slide 窗口即碰撞体高度语义（catalog pass 字段表达）

### 3. 障碍生成（模板 + 真可达性验证）

- 组合模板 10 种（tier 0-2 分层，权重抽样），`randomDefId` 按难度分层池抽取
- **Reachability 验证器**：事件图状态区间传播（车道×最早可用距离），转移含变道距离+反应窗守卫、跳跃/滑铲覆盖窗（提前量+锁定）、跨波合并验证。拒绝的组合不可能被实例化（拒绝即重掷 3 次，兜底单体同样过验证）——不是"留一条空道"的平凡解
- 安全区：弯道/特殊地块及缓冲带不生成（isSafeSpawnZone 前后多采样点）

### 4. 道具系统

磁吸（12s 同类延长）/护盾（1 层不叠加，挡一切撞击）/冲刺（3s ×1.5 速度+无敌，替换剩余）/倍率（10s ×2 碎片，同类延长）/饮水（即时解除踉跄减速）。状态过期、重开清空、HUD 活跃显示、拾取弹字齐备。

### 5. 难度系统

- D = min(里程/6000里, 1) **封顶**；速度曲线独立上限（13→29）
- 密度：间隔随 D 收紧但下限 = max(3, 速度×0.45s) —— **最小反应时间硬约束**
- 复杂度：tier 解锁（D≥1/3、≥2/3）+ 时机障碍 unlockD；转弯频率随 D 收缩（gapMax→gapMin+20）
- 道具概率随 D 补偿（×(1+0.6D)）

**调试期间测试发现并修复 6 个核心缺陷**（这正是测试资产的价值）：
1. timing 障碍占道仅在判定帧更新 → 逐帧更新（渲染/驱动/判定同源）
2. 冲刺缺速度倍率实现 → effectiveSpeed 接入
3. 计时器浮点残差（0.05−3dt≈2.7e-17≠0 → 道具/踉跄永久生效）→ epsilon 归零
4. 兜底单体路径绕过可达性验证（会实例化刚被拒绝的必死组合）→ 兜底同样过验证
5. 安全区拦截丢波 → 拦截即跳过该波（该波随区间推进自然重试）
6. spawnWave 提前 return 跳过碎片/道具分支 → 移除

## 遗留与说明

1. 驱动器残余死亡（极端难度 ≤1/30种子）为测试工具启发式局限，非游戏可达性缺陷——真人有完整前瞻；KNOWN_ISSUES #15 记录持续观察。
2. 时机障碍（滚石/摆木）的"扫过车道并集"验证偏保守（最坏情形），可能比实际更严——安全方向的误差。
3. 障碍视觉为几何体参数化占位，P2 后续以真实资产替换（vis 字段已留映射）。
4. 2D 回退渲染对 22 种障碍按 vis 基元+配色简化区分（KNOWN_ISSUES #16）。
