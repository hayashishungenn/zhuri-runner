# 游戏设计文档

> 题材：夸父逐日（中国上古神话）。玩法参考《神庙逃亡》核心循环：无尽奔跑、三车道闪避、跳跃/俯冲、拾取、死亡复活。
> 本文记录**当前已实现**的机制与数值（与代码一致，数值已迁移至 `assets/resources/game-config.json`）。

## 核心循环

标题界面 → 起跑 → 无尽奔跑（难度渐增）→ 受击（踉跄，可承受一次）/ 撞击 → 慢动作死亡 → 结算（观看广告复活一次 / 重新起跑）。
奔跑中可暂停（❚❚ 按钮/ESC/P），切后台自动暂停，恢复需手动确认。

## 基础规则

- **视角**：第三人称背身追尾视角（P1 前：2D 伪透视；P1 起：真3D 透视相机）。
- **世界**：三车道（左/中/右），障碍与拾取自远处（z=46）向玩家（z=0）移动，z<-2 移除。
- **计距**：`里 = dist × 3`（dist 为逻辑速度积分）。天空色调随进度变化：以 30000 里为尺度从深夜渐入暖阳。
- **速度曲线**：`速度 = 13 + min(dist × 0.045, 16)`，即 13 → 29 逻辑单位/秒封顶（约 8000 里后到达极速）。
- **里程碑**：每 1000 里弹字「日影渐近 · N 里」。

## 操作

| 输入 | 行为 |
|------|------|
| 左/右滑（←/→/A/D） | 变道（可连续，clamp 到 ±1） |
| 上滑（↑/W/空格） | 跳跃（时长 0.62s；起跳取消滑铲；空中不可二段跳） |
| 下滑（↓/S） | 俯冲（0.55s；空中俯冲斩断跳跃快速落地） |
| 点按（奔跑中） | 跳跃 |
| ❚❚ 按钮 / ESC / P | 暂停 ↔ 恢复（PC 调试） |
| 路口窗口内左/右滑 | **转向**（仅 3D 模式；窗口 = 路口前 8 逻辑单位开启，HUD 闪烁箭头提示） |

变道为缓动插值（lerp 系数 11/s）。起跑后首次操作前显示操作提示（闪烁）。
多点触控：仅首个触点驱动手势；来电等系统打断（TOUCH_CANCEL）丢弃手势不误触。

### 动作优先级（Phase 1 规则化）

| 当前状态 | 变道 | 跳跃 | 滑铲 |
|----------|------|------|------|
| 标题/死亡/暂停 | ✗ | ✗ | ✗ |
| 奔跑（地面） | ✓ | ✓ | ✓ |
| 空中（跳跃中） | ✓ | ✗（无二段跳） | ✓（俯冲斩断跳跃） |
| 滑铲中 | ✓ | ✓（起跳取消滑铲） | ✓（重置时长） |
| 踉跄中 | ✓ | ✓ | ✓（受踉跄豁免无敌保护，作为奔跑修正器） |
| 转弯窗口 | ✗（手势路由为转向） | ✓ | ✓ |

## 障碍与判定

| 障碍 | 规避方式 |
|------|----------|
| 岩（rock） | 同车道需**跳跃**躲避（跳跃窗口 jumpT ∈ 0.12~0.88 视为空中） |
| 横木（log） | 同车道需**俯冲**躲避 |
| 岩墙（wall） | 不可跳/冲穿越，**必须变道**（踉跄对墙无效） |

- 生成节奏：每累计 8 逻辑距离生成一排；45% 概率 1 个 / 55% 概率 2 个（车道不重复），类型均匀随机。
- 判定点：z < 0.55 时判定；同车道且未规避 → **受击分级**（见下）。无敌期撞 → 击碎障碍 + 震屏。
- 侧景装饰（树/岩）每 2.4 距离生成于两侧路外，纯视觉，无判定。

### 受击分级（Phase 1 新增，`player.stumble` 可配置）

| 情形 | 结果 |
|------|------|
| 健康状态下撞岩/横木 | **受击（踉跄）**：减速至 45% 持续 1.8s + 豁免无敌 1.5s + 击碎该障碍 + 弹字「踉跄！」 |
| 踉跄中再撞岩/横木 | **死亡**（踉跄期 1.8s > 豁免期 1.5s，留 0.3s 危险窗口） |
| 撞岩墙（任意状态） | **死亡** |

`player.stumble.enabled = false` 时恢复 P0 行为：任何首撞即死。

## 拾取：阳炎碎片

- 60% 概率随障碍排生成在**空车道**，5 个一组（z 间隔 1.5）。
- 拾取窗口：z ∈ (-0.5, 0.9) 且同车道。+1 计数并弹字。
- 结算页展示「拾得阳炎 × N」。P1 仅计数，P2 接入经济/能力。

## 死亡与复活（IAA 挂点）

- 撞击：进入 `dying` 慢动作（timeScale 0.25 渐复、震屏 16、红闪 0.5、扬尘），0.95s 后进入 `dead` 结算。
- 复活：每轮限一次。模拟广告：3 段倒计时 × 0.85s →「✓」→ 发奖。真机替换为 `wx.createRewardedVideoAd`（代码留有挂点）。
- 复活效果：清除 z>14 的全部障碍、无敌 2.2s（角色闪烁）、恢复奔跑。
- 放弃复活 →「重新起跑」回标题重置。

## HUD / UI

奔跑 HUD：距离（已逐 N 里）、速度（实时，含踉跄减速）、阳炎计数、静音与暂停按钮（右上）、操作提示（首次）。
速度 >19 时出现环绕速度线；死亡慢动作有上下黑边（电影感）+ 红闪 + 暗角。

## 微信平台与广告（Phase 7 已实现）

- 平台服务抽象（存储/生命周期/音频/屏幕/分享/广告），浏览器与微信双实现，不支持的能力明确返回状态
- 激励视频 5 场景（复活/结算翻倍/每日翻倍/限时神通/皮肤试用）：仅 `isEnded=true` 发奖，事务幂等，超时/取消/失败不阻断
- 插屏仅在自然结算节点，四重频控；广告位 ID 独立配置且留空（禁止编造）

## 外围系统（Phase 6 已实现）

- **灵光金币**：阳炎结算/任务/成就获得（统一事务接口幂等防重复），消费于皮肤与强化；无真实货币
- **每日任务**：32 模板按日期抽 3，完成领金币，跨日自动刷新，回拨防刷
- **成就**：60 项长期目标（距离/阳炎/局数/路口/越障/神通/四境/征途/金币/清凉/皮肤/强化/最佳）
- **能力强化**：神杖层数/甘霖降温/引聚时长/热适应/阳炎倍率各 2 级（花费 300-1100）——**不含速度类**，操作公平
- **存档 v2**：版本号+校验和+备份槽+v1 迁移；损坏自动回落，离线可玩
- **新手教程**：可跳过六步交互（切道/跳跃/滑铲/甘霖/神通/转弯），教程局稀疏生成，完成/跳过落档

## 特色玩法（Phase 4 已实现）

- **逐日**：太阳随进度西沉增大；无尽以最高纪录为目标（存档），征途 3 阶段（2000/4000/6000 里）通关达「弃杖化邓林」结局。
- **高温**：主题联动升温（荒漠 1.6×/渭水 0.7×），热满减速不致死；甘霖 −40、溪流水花 −10、保底 300 单位强制甘霖、≥80 红光预警。
- **神通**：桃木神杖（破切道/时机类 ×3 层）/御风疾行（×1.5 冲刺）/巨人之跃（跳程 ×1.35）/灵光引聚（吸附）/山岳护体（挡一切）/甘霖降临（解暑复振）+ 阳炎倍率；叠加=同类取优，异类独立。
- **双模式**：共享核心逻辑，模式仅影响征途判定与太阳进度；标题双按钮进入。

## 障碍目录（Phase 3 已实现，数据驱动）

22 种障碍（`assets/resources/obstacle-catalog.json` + schema 校验），按通行方式分四类：

| 通行方式 | 障碍（受击等级） |
|----------|------------------|
| 跳跃 | 岩石(踉跄)、尖岩(踉跄)、巨岩(死)、倒木(踉跄)、藤蔓(踉跄)、沟壑(死)、断桥(死)、溪流(踉跄)、火堆(踉跄)、火带(死区)、双岩(踉跄) |
| 滑铲 | 倒木横梁(踉跄)、低矮宽梁(踉跄)、石拱门(踉跄) |
| 切道 | 岩墙(死)、尖刺墙(死)、火墙(死)、高栅栏(死)、石阵(踉跄) |
| 时机 | 往返石墩(踉跄，摆动)、摆木(死，摆动)、滚石(死，横移) |

- 每种障碍携带：通行条件/受击等级/占道数/视觉形态/配色/难度解锁阈值（unlockD）
- 时机障碍按"扫过车道并集"参与可达性验证（保守最坏情形）
- 组合模板 10 种（单排/双排/跳跃链/跳滑链/墙阵/火廊/时机混搭等），带权重与难度层级（tier 0-2）

## 道具系统（Phase 3 已实现）

| 道具 | 效果 | 叠加规则 |
|------|------|----------|
| 磁吸 | 12s 内近处碎片自动吸附 | 同类延长 |
| 护盾 | 挡一次任何撞击（含墙/即死类），击碎障碍 | 不叠加（1 层） |
| 冲刺 | 3s 速度 ×1.5 + 无敌 | 同类取优（剩余时间取最大） |
| 倍率 | 10s 内碎片 ×2 | 同类延长 |
| 饮水 | 即时解除踉跄与减速 | 即时 |

生成概率随难度提升（itemChance ×(1+0.6D)）；HUD 显示活跃道具与剩余秒。

## 动态难度（Phase 3 已实现）

- D = min(里程/rampLi, 1)，**封顶**（速度曲线另有独立上限，避免无限加速）
- 密度：生成间隔随 D 收紧，但**下限 = max(绝对下限, 速度×反应守卫 0.45s)** —— 保证最小反应时间
- 组合复杂度：tier 0/1/2 随 D 解锁；时机障碍 unlockD 门槛
- 转弯频率：turnGapMax 随 D 向 gapMin+20 收缩
- 可达性验证：每波生成（含跨波合并）经 Reachability 验证器（状态区间传播：变道距离/跳跃覆盖/滑铲覆盖/反应窗），失败重掷，兜底单体也验证——**拒绝的组合不可能被实例化**

## 无限地图（Phase 2 已实现）

- **地块流**：直线/上坡/下坡/左弯/右弯/桥/悬崖/山洞/过渡 9 类，入口-出口-方向-长度-宽度-主题-生成点-边界全数据化；预生成 300 / 身后 30 回收，数量恒有界。
- **转弯**：世界空间 90°，路口前窗口内左右滑=转向（区分切道）；转错/错过=撞墙（无敌不豁免）；转弯段及前后 6 单位为无障碍缓冲带。
- **主题**：每 400 逻辑距离切换（黄昏→夜→黎明循环），过渡地块门架标识；跑道/路缘配色随主题变化。
- **2D 回退模式**无转弯（保持直线跑道）。
