# 游戏设计文档

> 题材：夸父逐日（中国上古神话）。玩法参考《神庙逃亡》核心循环：无尽奔跑、三车道闪避、跳跃/俯冲、拾取、死亡复活。
> 本文记录**当前已实现**的机制与数值（与代码一致，数值已迁移至 `assets/resources/game-config.json`）。

## 核心循环

标题界面 → 起跑 → 无尽奔跑（难度渐增）→ 受击（踉跄，可承受一次）/ 撞击 → 慢动作死亡 → 结算（观看广告复活一次 / 重新起跑）。
奔跑中可暂停（❚❚ 按钮/ESC/P），切后台自动暂停，恢复需手动确认。

## 基础规则

- **视角**：第三人称背身追尾视角（P1 前：2D 伪透视；P1 起：真3D 透视相机）。
- **世界**：三车道（左/中/右），障碍与拾取自远处（z=46）向玩家（z=0）移动，z<-2 移除。
- **计距**：`里 = dist × 3`（dist 为逻辑速度积分）。天空色调随进度变化：以 30000 里为尺度从深夜渐入暖阳。
- **速度曲线**：`速度 = 13 + min(dist × 0.045, 16)`，即 13 → 29 逻辑单位/秒封顶（约 8000 里后到达极速）。
- **里程碑**：每 1000 里弹字「日影渐近 · N 里」。

## 操作

| 输入 | 行为 |
|------|------|
| 左/右滑（←/→/A/D） | 变道（可连续，clamp 到 ±1） |
| 上滑（↑/W/空格） | 跳跃（时长 0.62s；起跳取消滑铲；空中不可二段跳） |
| 下滑（↓/S） | 俯冲（0.55s；空中俯冲斩断跳跃快速落地） |
| 点按（奔跑中） | 跳跃 |
| ❚❚ 按钮 / ESC / P | 暂停 ↔ 恢复（PC 调试） |
| 路口窗口内左/右滑 | **转向**（仅 3D 模式；窗口 = 路口前 8 逻辑单位开启，HUD 闪烁箭头提示） |

变道为缓动插值（lerp 系数 11/s）。起跑后首次操作前显示操作提示（闪烁）。
多点触控：仅首个触点驱动手势；来电等系统打断（TOUCH_CANCEL）丢弃手势不误触。

### 动作优先级（Phase 1 规则化）

| 当前状态 | 变道 | 跳跃 | 滑铲 |
|----------|------|------|------|
| 标题/死亡/暂停 | ✗ | ✗ | ✗ |
| 奔跑（地面） | ✓ | ✓ | ✓ |
| 空中（跳跃中） | ✓ | ✗（无二段跳） | ✓（俯冲斩断跳跃） |
| 滑铲中 | ✓ | ✓（起跳取消滑铲） | ✓（重置时长） |
| 踉跄中 | ✓ | ✓ | ✓（受踉跄豁免无敌保护，作为奔跑修正器） |
| 转弯窗口 | ✗（手势路由为转向） | ✓ | ✓ |

## 障碍与判定

| 障碍 | 规避方式 |
|------|----------|
| 岩（rock） | 同车道需**跳跃**躲避（跳跃窗口 jumpT ∈ 0.12~0.88 视为空中） |
| 横木（log） | 同车道需**俯冲**躲避 |
| 岩墙（wall） | 不可跳/冲穿越，**必须变道**（踉跄对墙无效） |

- 生成节奏：每累计 8 逻辑距离生成一排；45% 概率 1 个 / 55% 概率 2 个（车道不重复），类型均匀随机。
- 判定点：z < 0.55 时判定；同车道且未规避 → **受击分级**（见下）。无敌期撞 → 击碎障碍 + 震屏。
- 侧景装饰（树/岩）每 2.4 距离生成于两侧路外，纯视觉，无判定。

### 受击分级（Phase 1 新增，`player.stumble` 可配置）

| 情形 | 结果 |
|------|------|
| 健康状态下撞岩/横木 | **受击（踉跄）**：减速至 45% 持续 1.8s + 豁免无敌 1.5s + 击碎该障碍 + 弹字「踉跄！」 |
| 踉跄中再撞岩/横木 | **死亡**（踉跄期 1.8s > 豁免期 1.5s，留 0.3s 危险窗口） |
| 撞岩墙（任意状态） | **死亡** |

`player.stumble.enabled = false` 时恢复 P0 行为：任何首撞即死。

## 拾取：阳炎碎片

- 60% 概率随障碍排生成在**空车道**，5 个一组（z 间隔 1.5）。
- 拾取窗口：z ∈ (-0.5, 0.9) 且同车道。+1 计数并弹字。
- 结算页展示「拾得阳炎 × N」。P1 仅计数，P2 接入经济/能力。

## 死亡与复活（IAA 挂点）

- 撞击：进入 `dying` 慢动作（timeScale 0.25 渐复、震屏 16、红闪 0.5、扬尘），0.95s 后进入 `dead` 结算。
- 复活：每轮限一次。模拟广告：3 段倒计时 × 0.85s →「✓」→ 发奖。真机替换为 `wx.createRewardedVideoAd`（代码留有挂点）。
- 复活效果：清除 z>14 的全部障碍、无敌 2.2s（角色闪烁）、恢复奔跑。
- 放弃复活 →「重新起跑」回标题重置。

## HUD / UI

奔跑 HUD：距离（已逐 N 里）、速度（实时，含踉跄减速）、阳炎计数、静音与暂停按钮（右上）、操作提示（首次）。
速度 >19 时出现环绕速度线；死亡慢动作有上下黑边（电影感）+ 红闪 + 暗角。

## 无限地图（Phase 2 已实现）

- **地块流**：直线/上坡/下坡/左弯/右弯/桥/悬崖/山洞/过渡 9 类，入口-出口-方向-长度-宽度-主题-生成点-边界全数据化；预生成 300 / 身后 30 回收，数量恒有界。
- **转弯**：世界空间 90°，路口前窗口内左右滑=转向（区分切道）；转错/错过=撞墙（无敌不豁免）；转弯段及前后 6 单位为无障碍缓冲带。
- **主题**：每 400 逻辑距离切换（黄昏→夜→黎明循环），过渡地块门架标识；跑道/路缘配色随主题变化。
- **2D 回退模式**无转弯（保持直线跑道）。
