### 2. 游戏经济（core/Economy.ts）

- 灵光金币获得：跑酷（阳炎按倍率换金币，实时事务）、任务领取、成就领取
- 消费：皮肤购买、能力强化——**无任何真实货币功能**
- **统一奖励事务接口**：`Economy.grant(txId, amount)` 幂等（同 txId 只发放一次，512 条事务日志防重放）；`spend` 原子扣减（余额不足拒绝、无负数）

### 3. 成长系统（core/Upgrades.ts，5 系）

| 强化 | 每级效果 | 上限 | 花费曲线 |
|------|----------|------|----------|
| 神杖强化 | 层数上限 +1 | Lv2 | 400/900 |
| 甘霖强化 | 降温 +10 | Lv2 | 350/800 |
| 引聚强化 | 时长 +3s | Lv2 | 300/700 |
| 热适应 | 升温 -12% | Lv2 | 400/850 |
| 阳炎倍率 | 金币 +15% | Lv2 | 500/1100 |

**公平性硬约束**：五系强化均不触及移动速度/判定窗口——移动速度只由距离曲线与热满减速决定（上限封顶），角色养成无法导致不可控高速。长期目标：全满 6 级 ≈ 5000 金币 + 8 皮肤 ≈ 8400 金币。

### 4. 任务与成就

- **32 个每日任务模板**（≥30）：距离/金币/障碍/神通×6/路口/清凉/地图/征途，每日按日期种子稳定抽取 3 个；进度按累计值增量喂数（dt 无关）；**日期切换自动刷新 + 时间回拨防刷**（回拨维持当日）；异常时间输入回落默认不崩溃
- **60 项长期成就**：累计距离×6/阳炎×6/局数×5/路口×5/越障×5/击碎×4/神通 12/四境全访/征途×2/金币×4/清凉跑/饮水×2/皮肤×2/强化×2/最佳×3
- 领取幂等：claim 写入存档 claimed 仓，重复领取返回 false；成就解锁（数值达标）与领取分离

### 5. 存档系统 v2（platform/Save.ts 重写）

- **版本号** v2 + djb2 校验和；主档 `zhuri.save` + 备份槽 `zhuri.save.bak`
- 损坏处理：主档校验失败 → 读备份 → 均失败 → 默认值（测试：任意损坏不抛错可玩）

- 不收集个人信息（仅游戏数值与设置）
