# 总体路线图

> 目标（源自《夸父逐日》项目全局开发规范）：第三人称**真3D**无尽跑酷微信小游戏，可正式发布、长期运行、通过 IAA 广告获益。引擎锁定 Cocos Creator **3.8.8** + TypeScript。

## 阶段总览

| 阶段 | 内容 | 状态 | 验收标准（节选） |
|------|------|------|------------------|
| P0 | 可玩原型（2D Graphics 单文件） | ✅ 完成 | 浏览器预览可完整玩一轮；已达成（无验收记录，见 PROGRESS） |
| P1 | 模块化架构 + 数据驱动配置 + 单元测试 + 真3D渲染管线 | 🔄 进行中 | 见下方详细验收 |

## P1 详细验收标准（本阶段）

1. **架构**：核心游戏逻辑零 `cc` 依赖（纯 TypeScript），与渲染、输入、平台接口解耦；`Game.ts` 仅做引导装配。
2. **数据驱动**：全部游戏参数集中于 `assets/resources/game-config.json`，带结构校验（非法配置启动即报错，不静默回退魔法数字）。
3. **真3D**：`Renderer3D` 提供第三人称透视相机 + 运行时构建的 3D 跑道/障碍/角色/天空，作为默认渲染；`Renderer2D` 保留现有 2D 视觉作为回退，通过配置 `renderMode` 切换。
4. **测试**：核心机制（生成规则、碰撞判定、难度曲线、复活规则、广告模拟时序、配置校验）单元测试全部通过。
5. **构建**：Creator CLI 构建微信小游戏包成功，无 TypeScript 编译错误。
6. **Git**：全部变更原子提交，不推送远程。
7. **文档**：PROGRESS / TEST_REPORT / KNOWN_ISSUES 同步更新，人工验证项（编辑器预览、真机）单独列出，不伪造结果。

## P2 规划（预览）

- 美术资产替换几何体占位（须授权明确，记入 ASSET_LICENSES.md）
- 程序化音频 or 授权音效（起跑/拾取/撞击/里程碑/UI）
- 道具与能力（桃木杖冲刺、日照护盾等，数据驱动定义）
- 主题分段：黄昏 → 夜 → 黎明（当前已有 3 万里天空渐变基础）
- 本地存档：最佳纪录、累计阳炎（wx.storage 同步策略）

## P3 规划（预览）

- 微信真机兼容矩阵测试（iOS 高端/低端、Android 主流机型）
- 包体优化（分包、纹理压缩、Mesh 合批/DR：消 draw call）
- 分享与被动传播点（成绩卡片）
- 对象池全面替代 splice 数组（GC 抖动）
