## 7. 剩余风险清单

1. **发布配置**：`ad.mode='mock'`，五个广告位 ID 与插屏 ID 全空；真实广告不可用（政策禁止编造 ID）。需后台开通后配置并真机验证。
2. **主包体积**：构建目录 10.4MB（引擎 7.2MB）超过微信主包 4MB 的常见上限；需在微信开发者工具中确认实际分包/上传体积，必要时配置分包或裁剪引擎模块。此项未通过自动验证。
3. **真机性能**：30/60 FPS 目标未在设备验证；画质档位已提供，需按机型实测后确定默认档。
4. **存档数值信任模型**：djb2 无密钥校验只防误损坏，不防本地篡改；单机无真实货币，非经济漏洞。
5. **机器人平衡局限**：平衡模拟使用启发式自动驾驶，死亡数与真人水平不等价；仅用于相对比较。
